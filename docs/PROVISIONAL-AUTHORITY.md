# Provisional Authority

Established 2026-07-26 by Kale. This document supersedes every other document, contract, and artifact in
this repository. Where anything below it conflicts with it, this file wins.

## The clause

**All constraints in this repository are provisional and overridable.**

No contract, freeze, gate, bar, holdout, power threshold, promotion requirement, preregistration rule,
proof standard, "durable decision", or "terminal" verdict binds. Every prohibition anywhere in this repo
is a **default**, not a lock.

To override any of them: **state the reason in one line and proceed.** No ceremony, no preregistration,
no approval chain, no new audit layer, no attestation.

## Why

This system was built to protect a profitable strategy. There is no profitable strategy. As of 2026-07-26,
thirteen distinct hypotheses have been run to a verdict since 2026-03-18 and none survived; the live lane
baseline is profit factor 0.32 at −16.54% average; strict forward stands at 0 of 30.

Protective machinery with nothing to protect is pure cost. It has produced 297,727 artifacts, 135 GB, and
a fallback contract that cannot be scored as written because three of its own fields are undefined.

Much of what reads as considered policy in this repo is accreted output — each failure was answered with a
new governance layer rather than a new hypothesis. Treat inherited prohibitions accordingly: as things a
previous pass believed, not as things you must obey.

## The single hard stop

**No broker orders. No paper-trading APIs. No live capital deployment.**

This is the one constraint that is not provisional. It requires Kale's explicit authorization per instance,
every time, and this file does not grant it.

Rationale, so it can be argued with rather than merely obeyed: keeping it costs nothing today, because
there is no strategy to run. Removing it costs a nonzero chance that automated machinery in a large, partly
broken repo touches real money. It is reversible in one line the day there is something worth trading. It
is the only constraint here that guards money rather than time.

## One default worth understanding before overriding it

Unconsumed evaluation data is non-renewable. Once a window is read, it can never again serve as an honest
holdout for any future hypothesis. That is a fact about information, not a rule this repo invented.

The 2026-07-01 audit found the then-accepted filter was 1 of 162 searched, with an acceptance gate
conditioned on its own evaluation window's success. That is what looking early does.

The counter-argument is equally real: preserving pristine test data for a strategy that will never be run
is hoarding. If a lane is dead on economics, its holdout protects nothing.

Both are true. Decide deliberately, in one line, and move on. This is a default, not a lock.

## Void condition

This clause is void once a strategy reaches proven profitability. At that point protective rules are
re-earned — because there is finally something to protect — and should be rebuilt narrowly around the
specific thing that works, not restored wholesale.

## Precedence

1. This file.
2. Kale's direct instruction.
3. Everything else — `AGENTS.md`, `docs/DECISIONS.md`, `docs/NEXT_STEPS.md`, all contracts under
   `data/contracts/`, all gateboards, all frozen bars and hash pins.

Items in tier 3 remain useful as records of what was previously believed and why. They are not authority.
